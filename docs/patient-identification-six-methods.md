# 患者自動識別の6方式（比較検討案）

目的は共用血圧計の測定結果を正しい患者へ紐付けることです。以下は採用済みの方式ではなく、比較する候補です。

| 方式 | 仕組み | 主な利点 | 主な制約 |
|---|---|---|---|
| 1. ベッド位置推定（ESP32・BLE） | 病室に固定した受信機で血圧計の電波強度を比較 | 看護師の追加操作を抑えられる可能性 | 隣接ベッドの誤判定、電波遮蔽、本人確認不可 |
| 2. 電子インフォメーションボード連携 | 病室・ベッド割当と患者IDを正規の読取連携で取得 | 既存の割当情報を活用できる | 更新遅延、患者ID未保持、連携仕様不明 |
| 3. 血圧計の機器ID・測定時刻照合 | 機器固有IDと測定時刻を他の記録と突合 | 測定イベントを追跡しやすい | 共用機器だけでは患者を識別できない |
| 4. ベッド側固定ビーコン・近接検出 | ベッドごとに固定したBLE等の識別信号と測定機器を照合 | ベッド単位の補助情報となる | 電波混信、設置保守、本人確認不可 |
| 5. 患者リストバンドのバーコード・RFID等 | 測定時に患者固有の識別子を読み取る | 正しい運用下では識別の確実性を高められる | 読取操作・機器が必要で完全無操作の目標と相反 |
| 6. 患者本人による確認・看護師確認 | 氏名・生年月日など独立した情報を用い確認する | 誤登録防止の安全策 | 無操作の完全自動化はできない |

## 方針
位置推定・ボード連携・測定時刻照合を組み合わせても、患者本人である証明にはなりません。**不確かな場合は未割当で保留**し、臨床安全性が検証されるまで電子カルテに自動登録しません。顔認識等を検討する場合は別途、同意・プライバシー・精度・運用の審査が必要です。
